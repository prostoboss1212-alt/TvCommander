## 1. О проекте (Суть задачи)
- **Название:** TV Commander (`com.example.tvcommander`)
- **Назначение:** Мобильное приложение на Android (смартфон) для беспроводного управления телевизорами Android TV / Google TV по домашней сети Wi-Fi через прямой протокол ADB (без установки каких-либо серверных приложений на ТВ).
- **GitHub Репозиторий:** [github.com/prostoboss1212-alt/TvCommander](https://github.com/prostoboss1212-alt/TvCommander)
- **Прямая ссылка на скачивание APK:** [TvCommander.apk (Latest Release)](https://github.com/prostoboss1212-alt/TvCommander/releases/latest/download/TvCommander.apk)

## 2. Ключевой функционал приложения

### 🎮 1. Мгновенный тактильный пульт (Dual-Mode Remote 2.0)
- **Два режима управления на выбор:**
  - **Кнопки (D-Pad):** классический тактильный диск с виброоткликом (Вверх, Вниз, Влево, Вправо, центр OK).
  - **Сенсорный тачпад (Trackpad):** управление плавными жестами свайпов в 4 стороны и тапом в центр для нажатия OK.
- **Быстрый запуск программ прямо с пульта:** 1-тап запуск SmartTube, Кинопоиск, Lampa и Настроек ТВ (без необходимости переключаться во вкладку программ).
- **Быстрая клавиатура / поиск с телефона:** строка быстрого ввода текста со смартфона с отправкой на ТВ и кнопкой вставки из буфера обмена.
- **Аппаратная качелька громкости:** физические кнопки громкости на корпусе смартфона регулируют звук ТВ.
- **Таймер сна (Sleep Timer):** автовыключение ТВ через 15, 30, 45, 60, 90 минут с таймером обратного отсчета.
- **Скриншот экрана ТВ:** моментальный снимок экрана телевизора по ADB (`screencap -p`) в 100% качестве с просмотром в диалоге.

### ⚡ 2. Включение телевизора по Wi-Fi (Wake-on-LAN + Xiaomi MiTV API)
- Автоматическое пробуждение спящего Xiaomi Mi TV (`MITV-MSSP1`, `192.168.68.108`, MAC `da:a7:fc:93:e4:99`) в 1 клик.
- **Усиленный сетевой стек:**
  - Приобретение `WifiManager.MulticastLock` во избежание сброса UDP-пакетов энергосбережением Android.
  - Мультиадресная рассылка пакетов Magic Packet (`255.255.255.255`, направленный подсетевой broadcast `192.168.68.255` и прямой юникаст `192.168.68.108`) по портам 9 и 7 тремя пачками.
  - Параллельный вызов нативного сервисного API Xiaomi Mi Remote на порту `6095/8345` (`/controller?action=keyevent&keycode=power`).
  - Цикл автоподключения ADB с retry (до 6 попыток с задержкой 800 мс) с ожиданием подъема Wi-Fi модуля телевизора (~2-3 сек).
  - Отправка кодов включения экрана (`KEYCODE_WAKEUP` 224) и перехода на главный экран (`KEYCODE_HOME` 3).
- **Интерактивная плашка на пульте:** при отсутствии связи отображается красная карточка включения со встроенной инструкцией по настройке Xiaomi TV.

### 🚀 3. Комплексная вкладка «Очистка» (Глубокая оптимизация ТВ)
- **Мониторинг ресурсов в реальном времени:** точные показатели свободной/занятой RAM (`/proc/meminfo`) и хранилища (`df /data`).
- **Турбо-ускорение в 1 клик:**
  1. Глубокий сброс кэша всех приложений (`pm trim-caches 999999999999` + `rm -rf /data/local/tmp/*`).
  2. Выгрузка спящих фоновых зомби-процессов и освобождение RAM (`am kill-all`).
  3. Аппаратная оптимизация флеш-накопителя (`sm fstrim`).
  4. Ускорение системных анимаций в 2 раза (`window_animation_scale 0.5`).
- **Блокировка рекламы на ТВ (AdGuard DNS в 1 клик):** системная фильтрация баннеров и трекеров через `private_dns_specifier dns.adguard-dns.com`.
- **Выборочная оптимизация:** отдельные кнопки для очистки кэша, выгрузки RAM, TRIM памяти, очистки буферов logcat.
- **Переключатель скорости меню:** Мгновенно (0.0x), Турбо (0.5x), Стандарт (1.0x).

### 📺 4. Оптимизированные лаунчеры (Вкладка «Лаунчеры»)
- **1-клик установка прямо из приложения** (без ручного поиска APK пользователем):
  - **FLauncher** (ультралегкий, Open Source, Flutter).
  - **Projectivy Launcher** (официальный релиз 4.73 от Spocky с аппаратным ускорением).
  - **ATV Launcher Pro** (классика для ТВ с 1 ГБ ОЗУ, виджеты).
  - **Akari Launcher** (ультралегкий ~500 КБ, потребляет <30 МБ RAM).
  - **CuteLauncher** (премиальный интерфейс в стиле Apple tvOS).
- **Кнопка «Инфо»** с описанием, плюсами/минусами и расходом RAM.
- **Функция «Откат к заводской оболочке»** с подтверждением (Xiaomi PatchWall / TCL Home / Google TV).

### 🍿 5. Топ-приложения для ТВ в 1 клик (Вкладка «Программы»)
- Готовый каталог проверенных приложений без поиска APK:
  - **SmartTube** (YouTube без рекламы со SponsorBlock).
  - **Lampa AIO** (онлайн-кинотеатр со встроенными плагинами).
  - **TorrServe Matrix** (онлайн-просмотр торрент-фильмов без скачивания).
  - **VLC Player** (всеядный медиаплеер).

### ⚙️ 6. Настройки и персонализация (Вкладка «Опции»)
- **4 динамические темы оформления:**
  - 💎 **Cyber Cyan:** неоновый бирюзовый OLED (по умолчанию).
  - 🔮 **Amethyst:** глубокий неоново-фиолетовый.
  - 🌿 **Emerald:** матричный изумруд.
  - 🔥 **Crimson:** огненно-красный OLED.

  - Переключатель «Не гасить экран смартфона» (Keep Screen On).
  - Автоподключение при старте приложения.
- **Профили ТВ:**
  - Переключение в 1 клик между Xiaomi Mi TV и TCL Smart TV Pro.
  - Сканирование локальной сети (поиск открытого порта 5555).
  - Ручное добавление и редактирование IP/MAC.

## 3. Целевое оборудование пользователя
- **Модель телевизора 1 (Основной):** Xiaomi Mi TV (`MITV-MSSP1`)
  - **IP:** `192.168.68.108`
  - **Порт ADB:** `5555`

  - **IP:** `192.168.68.106`
  - **Порт ADB:** `5555`

## 4. Технологический стек
- **Язык:** Kotlin 2.0.0 (целевая JVM 17)
- **UI:** Jetpack Compose (BOM `2024.06.00`), Material 3, Material Icons Extended
- **Android SDK:** Compile SDK 34 (Android 14), Min SDK 26 (Android 8.0+), Target SDK 34
- **Архитектура:** Single Activity (`MainActivity.kt`) + MVVM (`TvViewModel.kt` с Kotlin Coroutines & StateFlow)
- **Сетевой ADB-движок:** `dev.mobile:dadb:1.2.6` (чистый сокетный протокол, не требует adb binaries)
- **Хранение настроек:** Jetpack DataStore Preferences (`PreferencesManager.kt` с JSON-сериализацией устройств)
